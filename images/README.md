# Dossier `images/`

Mettez ici vos photos de référence, puis référencez-les dans `prompts.js`
via un chemin relatif :

```
{ id: 'meme-success-kid', ..., image: 'images/meme-success-kid.jpg' }
```

Convention conseillée : nommer le fichier avec l'`id` de la carte
(visible dans `prompts.js`), pour retrouver facilement quelle image va
avec quelle carte.

⚠️ Ces fichiers font partie du projet : si vous poussez le dossier sur
GitHub/GitLab (notamment pour l'hébergement Pages), toute image mise ici
sera publiée avec le dépôt. Pour des photos protégées par le droit
d'auteur (memes, captures de films...) destinées à un usage privé,
gardez le dépôt **privé**, ou utilisez plutôt le bouton « 🖼️ Photo de
référence » dans l'appli (stockage local au navigateur, jamais commité).
